# Add a "Report a Bug" link to the user menu

Add a "Report a Bug" link to the user dropdown menu (top-right avatar)
of the signed-in Plane UI that opens https://github.com/makeplane/plane/issues/new
in a new tab.

## How to reach the app

Plane runs on http://localhost:8080. First-time use requires signing up
a new account on the home page.

## Acceptance

- "Report a Bug" entry is visible in the user dropdown menu for signed-in users.
- Clicking it opens github.com/makeplane/plane/issues/new in a new tab
  (target=_blank, rel=noopener).
- No existing menu items are removed or moved.
